## Tneħħija Rapida (v3.6.2+)

AgentProxy tipprovdi żewġ skripts interni għat-tneħħija nadif:

### Ħu Ġejjiena Data Tiegħek

```bash
npm run uninstall
```

Dan ineħħi l-applikazzjoni AgentProxy iżda **jippreserva** d-database, il-konfigurazzjonijiet, iċ-ċav API, u t-taħdid tal-fornituri f'`~/.agentproxy/`. Għoġbok dan jekk tixtieq terġa' tinstalla aktar tard u trid iżżomm l-issettjar tiegħek.

### Tneħħija Sħiħa

```bash
npm run uninstall:full
```

## Tneħħija Manwali

### Installazzjoni Globali NPM

```bash
# Neħħi l-pakkett globali
npm uninstall -g agentproxy

# (Fakultattiv) Neħħi d-direttorija tad-dejta
rm -rf ~/.agentproxy
```

### Installazzjoni Globali pnpm

```bash
pnpm uninstall -g agentproxy
rm -rf ~/.agentproxy
```

### Docker

```bash
# Waqaf u neħħi l-kontenitur
docker stop agentproxy
docker rm agentproxy

# Neħħi l-volum (jelimina l- dejta kollha)
docker volume rm agentproxy-data

# (Fakultattiv) Neħħi l-istampa
docker rmi khanhkit/agentproxy:latest
```

### Docker Compose

```bash
# Waqaf u neħħi l-kontenituri
docker compose down

# Neħħi ukoll il-volumi (jelimina l-dejta kollha)
docker compose down -v
```

### App tal-Desktop Electron

**Windows:**

- Agħlaq `Settings → Apps → AgentProxy → Uninstall`
- Jew ħdimma l-uninstaller NSIS mid-direttorija tal-installazzjoni

**macOS:**

- Seħħi `AgentProxy.app` minn `/Applications` lejn il-ħmieġ
- Neħħi d-dejta: `rm -rf ~/Library/Application Support/agentproxy`

**Linux:**

- Neħħi l-fajl AppImage
- Neħħi d-dejta: `rm -rf ~/.agentproxy`

### Installazzjoni minn sors (git clone)

```bash
# Neħħi d-direttorija maqsuma mal-oħrajn
rm -rf /path/to/agentproxy

# (Fakultattiv) Neħħi d-direttorija tad-dejta
rm -rf ~/.agentproxy
```

## Direttoriji tal-Dejta

AgentProxy jiffranka d-dejta fil-lokazzjonijiet li ġejjin b'mod assolut:

| Pjattaforma      | Triq Assoluta                 | Override                               |
| ---------------- | ----------------------------- | -------------------------------------- |
| Linux            | `~/.agentproxy/`               | Varjanti tal-ambjent `DATA_DIR`        |
| macOS            | `~/.agentproxy/`               | Varjanti tal-ambjent `DATA_DIR`        |
| Windows          | `%APPDATA%/agentproxy/`        | Varjanti tal-ambjent `DATA_DIR`        |
| Docker           | `/app/data/` (volum maħruġ)   | Varjanti tal-ambjent `DATA_DIR`        |
| Konformi mal-XDG | `$XDG_CONFIG_HOME/agentproxy/` | Varjanti tal-ambjent `XDG_CONFIG_HOME` |

### Fajls fid-direttorija tal-dejta

| Fajl/Direttorija     | Deskrizzjoni                                                 |
| -------------------- | ------------------------------------------------------------ |
| `storage.sqlite`     | Database ewlieni (fornituri, kombo, impostazzjonijeti, kijs) |
| `storage.sqlite-wal` | Log tal-kitba ta' qabel SQLite (temporary)                   |
| `storage.sqlite-shm` | Memorja maqsuma SQLite (temporary)                           |
| `call_logs/`         | Arċivji tal-pagament tal-ħatriet                             |
| `backups/`           | Riservi awtomatiċi tal-database                              |
| `log.txt`            | Log tal-ħatriet leġiżlu (fakultattiv)                        |

## Tverifika t-Tneħħija Kompleta

Wara t-tneħħija, tivverifika li ma jkunx hemm fajls li fadal:

```bash
# Ġejja tivverifika l-pakkett npm globali
npm list -g agentproxy 2>/dev/null

# Ġejja tivverifika d-direttorija tal-dejta
ls -la ~/.agentproxy/ 2>/dev/null

# Ġejja tivverifika l-proċessi li qed jaħdmu
pgrep -f agentproxy
```

Jekk xi proċess għadu qed jaħdem, waqfu:

```bash
pkill -f agentproxy
```
