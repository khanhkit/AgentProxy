- **fix(sse):** Antigravity can now reserve the account selected for a request for that request's streaming lifecycle, preventing concurrent routing from re-picking an account already committed to an in-flight stream. A fully leased pool returns a structured `503` with code `antigravity_pool_busy` and a bounded `Retry-After`. This is opt-in behind `ANTIGRAVITY_ACCOUNT_LEASE_ENABLED` (default off).
